# TASK-000 确认硬件与通信基线

## 目标

收集创建可构建 STM32 工程所需的真实硬件信息，消除 Phase 0 的阻塞项。

## 范围

- 开发板、MCU、调试器和 Cube 固件包版本。
- UART、ADC、RS485 DE/RE 引脚及收发器型号。
- 传感器/电位器类型、量程、供电和接线。
- 默认 Slave ID、波特率、校验和停止位。
- 阈值范围、默认值和迟滞值。

## 非范围

不实现固件功能，不修改协议架构，不接入高压或市电设备。

## 验收标准

1. 上述信息写入固件 README 或硬件配置文档。
2. 信息足以生成唯一、可复现的 Cube 工程。
3. 寄存器表中的范围、字序和状态定义已评审。

## 当前状态

待用户提供硬件信息；该任务阻塞 STM32 工程生成，但不阻塞 Qt 最小骨架与 Fake 通信测试准备。
