# TASK-000 确认硬件与通信基线

## 目标

收集创建可复现 STM32 工程所需的真实硬件信息，确定当前阶段的时钟、引脚、电气、数据和通信参数。

## 范围

- 开发板、MCU、调试器、CubeMX 和 Cube 固件包版本。
- UART、三路 I2C、ADC、传感器供电与接线。
- 当前 VCP/USART2 通信参数。
- 默认温度阈值、迟滞、数据缩放、字序和状态位。
- 明确当前不存在 RS485 模块，并建立后续迁移任务。

## 非范围

- 不生成或构建固件工程。
- 不进行接线、烧录或真实硬件测量。
- 不虚构尚未购买的 RS485 收发器型号和测试结果。

## 交付物

- `docs/hardware_baseline.md`
- `docs/modbus_register_map.md`
- `tasks/TASK-002-rs485-hardware-migration.md`
- 同步后的架构、PRD、README 和 Phase 0 文档

## 验收结果

1. 已确定 NUCLEO-F411RE、STM32F411RET6、ST-LINK/V2-1、CubeMX 6.18.1-RC2 与 STM32CubeF4 v1.28.3。
2. 已确定 HSI/PLL 100 MHz 工程时钟方案，不依赖 MB1136 板修订的 HSE 焊桥。
3. 已为三只固定地址 `0x44` 的 DHTC12 分配 I2C1/2/3，并确定 3.3 V、4.7 kΩ 上拉和 100 kHz。
4. 已确定光敏模块使用 3.3 V、PA0/ADC1_IN0 和 0～3300 mV 数据表示。
5. 已确定 Modbus RTU 当前通过 USART2 VCP、115200 8N1、Slave ID 1 验证。
6. 已评审寄存器范围、低字在低地址的 32 位字序、告警位、设备状态位和错误计数策略。
7. 已将真实 RS485 收发器与 DE/RE 接线移交 `TASK-002`，不阻塞 TASK-001 的最小 Cube 工程。

## 验证说明

完成的是资料与设计基线评审，不是硬件运行验证。所有硬件行为仍须在后续任务中用实物证据验证。
