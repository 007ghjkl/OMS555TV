# TASK-002 选择并验证 RS485 硬件迁移方案

## 目标

在获得 TTL-RS485 模块后，把已验证的 Modbus RTU 协议从 ST-LINK VCP/USART2 迁移到真实的半双工 RS485 物理层。

## 范围

- 选择 3.3 V 供电或 3.3 V 逻辑兼容的半双工 RS485 收发器模块。
- 确认 A/B、RO、DI、DE、/RE、VCC 和 GND 接线。
- 评审 USART 资源；优先验证 USART1 PA9/PA10 + PC8 DE/RE，以保留 USART2 VCP 调试日志。
- 确认 DE 与 /RE 的组合方式、发送前后时序、终端电阻和偏置。
- 使用 USB-RS485 转换器验证双向通信、异常恢复和原始帧。

## 非范围

- 不在模块型号未确认时写死 GPIO 或电气参数。
- 不接入高压、市电或非安全低压系统。

## 依赖

- 实际 TTL-RS485 模块及其数据手册。
- USB-RS485 转换器。
- 已通过 VCP/UART 验证的 Modbus RTU Slave。

## 验收标准

1. 模块型号、逻辑电平、引脚和接线进入硬件基线。
2. CubeMX 引脚分配与实物接线一致，无 ST-LINK 或 I2C/ADC 冲突。
3. 115200 8N1 下可通过真实 RS485 连续读写。
4. DE/RE 不截断帧，空闲时总线方向正确。
5. 报告明确记录线长、终端/偏置、转换器和测试证据。

## 当前状态

待采购硬件后开始；不阻塞 Phase 0/1，阻塞 Phase 2 的 RS485 电气层验收。
