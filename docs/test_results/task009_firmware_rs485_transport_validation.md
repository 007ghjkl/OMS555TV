## 3. 协议与数据验证

第三方 Master 经 COM6 完成以下真实双向 RS485 操作：

- 全部合法读块 `0～4`、`9～12`、`19～20`、`29～31`、`39～40` 均读取成功；
- 初始快照包含 A/B/C 温度 27.1/26.9/27.0 ℃、环境温度 25.0 ℃、光敏 2201 mV、状态 `0x0021`、固件版本 0.2；
- A/B/C/环境阈值分别写入 55.0/80.0/-40.0/45.0 ℃并回读成功；测试后恢复为 60.0/60.0/60.0/40.0 ℃；
- 保留地址读取返回异常码 `0x02`；越界阈值 80.1 ℃返回异常码 `0x03`；
- 不支持功能返回异常码 `0x01`，原始响应为 `01 90 01 8D C0`；
- 错误 CRC 和短帧均无响应，通信错误计数依次由 0 增至 1、2；后续合法请求恢复成功；
- 无请求监听 3 秒，未收到 ASCII 或其他 unsolicited bytes。

这些结果同时证明 COM6→USART1 请求路径和 USART1→COM6 响应路径可达，补齐了此前只有单向文本发送的证据。
