## 2. 告警状态字 40020

| 位 | 名称 | 置位条件 |
|---:|---|---|
| 0 | A_PHASE_TEMP_HIGH | A 相温度达到阈值 |
| 1 | B_PHASE_TEMP_HIGH | B 相温度达到阈值 |
| 2 | C_PHASE_TEMP_HIGH | C 相温度达到阈值 |
| 3 | AMBIENT_TEMP_HIGH | 环境温度达到阈值 |
| 4～15 | RESERVED | 固定为 0 |

温度降至 `threshold - 5.0 ℃` 或更低时清除相应告警。

## 3. 设备状态字 40021

|---:|---|---|
| 0 | RUNNING | 主循环与采集调度已启动 |
| 1 | A_SENSOR_FAULT | A 相 DHTC12 无有效数据 |
| 2 | B_SENSOR_FAULT | B 相 DHTC12 无有效数据 |

| 4 | LIGHT_ADC_FAULT | ADC 值越界或采集不可用 |

| 6～15 | RESERVED | 固定为 0 |

## 4. 多寄存器与字节序

- 每个 16 位寄存器按 Modbus 规范高字节先传输。
- 32 位运行时间采用低字在低地址：`uptime = reg[40031] | (reg[40032] << 16)`。
- 同一条 0x03 请求读取 40031～40032 时，Slave 必须先生成快照，避免低字进位导致撕裂读取。

## 5. 通信错误计数口径

以下事件计入 40030：UART overrun/framing/noise/parity error、CRC 错误帧以及接收后因帧间超时判定的不完整帧。合法请求触发的 Modbus 标准异常响应不计入通信错误。计数达到 65535 后保持饱和。

## 6. 异常响应

- `0x01 Illegal Function`：不支持的功能码。
- `0x02 Illegal Data Address`：起始地址、地址范围或写目标不存在/不可写。
- `0x03 Illegal Data Value`：请求数量非法或阈值写入值超范围。

## 7. 当前限制

- MVP 仅要求功能码 0x03 和 0x06；0x04、0x10 和 Raw Frame 需单独任务确认。
- 生产物理链路为 USART1/自动换向 TTL-RS485；当前约 20 cm 安全低压点对点台架已完成双向读写、异常、连续请求和恢复验证。USART2/ST-LINK VCP 仅保留为编译期可选回归端点。
- DHTC12 原始温度已由 TASK-003 实物采样确认按大端有符号 16 位解释；该结论不表示温度经过计量校准。
- 当前结论不覆盖多 Slave、工业长线、终端/偏置设计、隔离或 EMC。

## 8. 实现一致性审计

| 核对项 | Firmware | Host | 正式测试资产 | 结论 |
|---|---|---|---|---|
| 已实现 PDU 地址集合 | `register_map.c` 中 16 个地址 | `HoldingRegister` 中 16 个地址 | Phase 5～7 正式套件使用合法地址或显式非法边界 | 一致 |
| 连续读块 | 0～4、9～12、19～20、29～31、39～40 | `deviceSnapshotReadBlocks` 为相同五块 | Phase 5/6 读取相同块或其合法子集 | 一致 |
| 温度与阈值 | `int16`，×0.1 ℃，-400～800 | 二补码解码与写入精度/范围校验 | 边界与负值 fixture、真实阈值写回读 | 一致 |
| 状态位 | 告警 `0x000F`、设备状态 `0x003F` | 相同 known mask | 正式状态字读取用例 | 一致 |
| 运行时间 | 低字在 PDU 30，高字在 PDU 31 | `low | high << 16` | `TC-D002/003` | 一致 |
| 异常响应 | 0x01/0x02/0x03 | 结构化 Modbus 异常 | 非法地址、超范围、跨界用例 | 一致 |
