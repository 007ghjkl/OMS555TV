## 异常响应

- `0x01 Illegal Function`：不支持的功能码。
- `0x02 Illegal Data Address`：地址或地址范围不存在。
- `0x03 Illegal Data Value`：写入值超出允许范围或请求数量非法。

## 实现前必须确认

1. 温度与阈值的有效范围、默认阈值和迟滞值。
2. 运行时间的单位、双寄存器字序和读取一致性策略。
3. 设备状态的枚举/位定义及传感器故障位。
4. 通信错误计数的统计口径与溢出行为。
5. 是否将实时数据放入 Input Registers 并支持功能码 0x04。
