> 状态：硬件基线 1.0；固件实现前仍需由协议单元测试验证
>
> 地址规则：文档编号 40001 对应 PDU 0-based 地址 0。

## 2. 告警状态字 40020

| 位 | 名称 | 置位条件 |
|---:|---|---|
| 0 | A_PHASE_TEMP_HIGH | A 相温度达到阈值 |
| 1 | B_PHASE_TEMP_HIGH | B 相温度达到阈值 |
| 2 | C_PHASE_TEMP_HIGH | C 相温度达到阈值 |
| 3 | AMBIENT_TEMP_HIGH | 环境温度达到阈值 |
| 4～15 | RESERVED | 固定为 0 |

温度降至 `threshold - 5.0 ℃` 或更低时清除相应告警。

## 3. 设备状态字 40021

| 位 | 名称 | 说明 |
|---:|---|---|
| 0 | RUNNING | 主循环与采集调度已启动 |
| 1 | A_SENSOR_FAULT | A 相 DHTC12 无有效数据 |
| 2 | B_SENSOR_FAULT | B 相 DHTC12 无有效数据 |
| 3 | C_SENSOR_FAULT | C 相 DHTC12 无有效数据 |
| 4 | LIGHT_ADC_FAULT | ADC 值越界或采集不可用 |
| 5 | AMBIENT_SIMULATED | 环境温度来自软件模拟值；当前硬件固定为 1 |
| 6～15 | RESERVED | 固定为 0 |

## 4. 多寄存器与字节序

- 每个 16 位寄存器按 Modbus 规范高字节先传输。
- 32 位运行时间采用低字在低地址：`uptime = reg[40031] | (reg[40032] << 16)`。
- 同一条 0x03 请求读取 40031～40032 时，Slave 必须先生成快照，避免低字进位导致撕裂读取。

## 5. 通信错误计数口径

以下事件计入 40030：UART overrun/framing/noise/parity error、CRC 错误帧以及接收后因帧间超时判定的不完整帧。合法请求触发的 Modbus 标准异常响应不计入通信错误。计数达到 65535 后保持饱和。

## 6. 异常响应

- `0x01 Illegal Function`：不支持的功能码。
- `0x02 Illegal Data Address`：起始地址、地址范围或写目标不存在/不可写。
- `0x03 Illegal Data Value`：请求数量非法或阈值写入值超范围。

## 7. 当前限制

- MVP 仅要求功能码 0x03 和 0x06；0x04、0x10 和 Raw Frame 需单独任务确认。
- 当前物理链路是 ST-LINK VCP/USART2，尚未完成 RS485 电气层验证。
- DHTC12 原始温度有符号解释必须经实物验证后，才可将数据一致性测试标记通过。
