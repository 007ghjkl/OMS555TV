## 1. 目的与范围

本文定义 NUCLEO-F411RE、自动换向 TTL-RS485 模块和 DTECH USB-RS485/422 转换器之间的安全低压点对点接口，作为 TASK-009 Firmware USART1 迁移和 TASK-010 Host 真实 RS485 联调的唯一硬件基线。

本文只约束：

- USART1、TTL 逻辑侧、RS485 总线侧和 USB 转换器的接线；
- 供电、电平、方向控制、公共参考地、拓扑、终端和偏置；
- 断电核对、上电顺序和测试门禁；
- 自动换向条件及 Firmware/Host 必须验证的 turnaround 行为。

本文不修改 Modbus Slave ID、寄存器表、业务模型、Host 公共通信契约或协议功能码。

## 3. 硬件身份

### 3.1 DUT

- 开发板：NUCLEO-F411RE，主板 `MB1136-F411RE-C04`；
- MCU：STM32F411RET6；
- Modbus 物理 UART：USART1；
- 历史回归通道：USART2/ST-LINK VCP，不与 RS485 构建同时作为 Modbus Slave。

### 3.2 TTL-RS485 模块

- 模块类别：无品牌/无商品型号的自动换向 TTL-RS485 红色模块；
- 主收发器：实物丝印目视为 `MAX13487 ESA LMW 504`，按封装命名和功能识别为 `MAX13487EESA` 系列；`LMW 504` 按批次/日期类追踪码记录，不作为型号；
- TTL 端：`VCC`、`RXD`、`TXD`、`GND`；
- 总线端：`A`、`B`、`GND`；
- 方向：模块自动控制，不暴露 DE 或 `/RE`；
- MCU 不使用 PC8，也不增加虚构方向 GPIO；
- 板载终端：R16 短接时接入 120 Ω；当前 R16 未短接，板载 120 Ω 未接入；
- 供电：实物使用 NUCLEO 5 V；MAX13487E 原厂额定供电范围为 4.75～5.25 V；
- 逻辑兼容：PA9 的 3.3 V 高电平高于 MAX13487E DI 最小高阈值 2.0 V；PA10 为 FT I/O，可接收模块 5 V 侧 RO。该结论只适用于信号脚，模块 VCC 不连接 MCU GPIO。

### 3.3 USB-RS485 转换器

- 资料标识：DTECH `IOT5081 Manual`，USB 2.0 转 RS485/422 串口线；
- Windows USB 串口桥身份：MacroSilicon，VID/PID `345F:3020`；
- RS485 收发器芯片：手册未披露，不得用 USB VID/PID 代替；
- 供电：USB 总线供电，不另接外部电源；
- 方向：内部自动换向，不需要 RTS/DTR 或跳线；
- DB9 引脚：1=`T/R+`=`RS485(A+)`，2=`T/R-`=`RS485(B-)`，5=`GND`。

## 4. 最终接线

### 4.1 MCU 到 TTL-RS485 模块

| NUCLEO/STM32 | TTL-RS485 | 方向 | 约束 |
|---|---|---|---|
| PA9 / USART1_TX | RXD | MCU → 模块 | 3.3 V UART 信号 |
| PA10 / USART1_RX | TXD | 模块 → MCU | 资料声明兼容 3.3 V 控制，PA10 为 FT I/O |
| NUCLEO 5 V | VCC | 供电 | 当前实物连接；只使用这一处电源 |
| GND | GND | 公共参考 | 与 USB 转换器 GND 连通 |
| PC8 | 不连接 | 不适用 | 自动换向方案禁止添加 DE/RE 控制 |

### 4.2 RS485 总线到 USB 转换器

| TTL-RS485 | USB-RS485 | 含义 |
|---|---|---|
| A | T/R+ / DB9-1 | A+，非反相线 |
| B | T/R- / DB9-2 | B-，反相线 |
| GND | GND / DB9-5 | 公共参考地 |

用户已确认当前总线侧只连接 `T/R+`、`T/R-`、`GND`，符合两线半双工接法。`RXD+`、`RXD-` 仅用于 RS422/四线模式，在本项目保持不连接。

如果实测完全无响应，可以把 A/B 极性错误列为诊断假设，但不得带电随意短接或把 GND 与差分端互换。

## 5. 串口与协议参数

| 参数 | 固定值 |
|---|---|
| 模式 | 两线半双工 RS485 / Modbus RTU |
| Slave ID | 1 |
| Baud rate | 115200 |
| Data bits | 8 |
| Parity | None |
| Stop bits | 1 |
| Flow control | None |
| Host 初始响应超时 | 500 ms |
| 隐式重试 | 0 |

两端转换器均自动换向。Firmware 只控制 USART1 TX/RX：阻塞发送函数必须在最后停止位发送完成后返回；模块自行完成驱动使能和接收恢复。Host 不使用 RTS/DTR 控制方向。

## 6. 方向与 turnaround 规则

1. 上电和空闲时，TTL 模块不得持续驱动 A/B；USART1 接收保持挂接。
2. Master 完整发送请求并释放总线后，TTL 模块自动进入接收；Firmware 收到完整请求并生成响应。
3. Firmware 通过 USART1 发送响应；底层必须等待 UART TC，而不是只等待 TXE。
4. TTL 模块根据 TXD 自动切换到发送，并在最后一位后自动回到接收。
5. Firmware 不产生 DE/RE GPIO、不写 PC8，也不在协议层添加固定方向延时。
6. 5 字节异常响应、8 字节 0x06 回显和连续最短 0x03 请求必须实测，用结果证明自动换向延时满足 115200 8N1。
7. 若实测出现本地回显、响应截断或连续请求丢失，应登记缺陷并停止门禁；不得用增加隐式重试掩盖方向问题。

## 7. 拓扑、终端与偏置

- 拓扑：单 Master、单 Slave、两端点、无支线的短距离台架总线；
- 线缆：当前三线约 20 cm；A/B 应并行成对布线，GND 随行；
- 公共参考：两端 GND 必须连接；现有 USB 转换器资料没有隔离声明，因此不得描述为隔离链路；
- 终端：当前约 20 cm 点对点台架链路，TTL 模块 R16 未短接，板载 120 Ω 未接入；USB 手册未披露内部终端，报告不得声称 USB 端存在或不存在终端。以实际连续请求和空闲行为验收当前短线配置；
- 偏置：两份资料均未提供可核验的偏置阻值或跳线。当前不外加偏置电阻，以空闲稳定性、无 unsolicited bytes 和连续请求结果验证；如出现空闲噪声，再单独测量/评审唯一偏置源；
- 断电测量：如需确认终端，应拔掉 USB 和 NUCLEO 电源后测量 A-B 等效电阻。禁止带电用电阻档测量。

## 9. 安全与操作顺序

1. 所有线路仅连接安全低压设备，禁止接入市电、真实电力线路或未知地电位设备。
2. 修改 VCC、RXD/TXD、A/B、GND、R16 或测量电阻前，先断开 NUCLEO USB 和 USB-RS485。
3. 先接公共地，再接 A/B；确认无短路后上电。
4. TTL 模块 VCC 只能选择一个电源，不得把 USB 转换器的 USB 供电与 NUCLEO 5 V 直接并联。
5. 不把 RS485 差分端接入 STM32 GPIO；PA9/PA10 只连接模块 TTL 端。
6. 烧录仍经 ST-LINK/SWD 完成；RS485 COM 端口只用于协议通信。

## 11. 评审记录

### 11.1 已关闭问题

1. **方向方案不确定。** 两份模块资料均明确自动换向，确定采用方案 B；不使用 PC8/DE/RE。
2. **USB 端 A/B 名称可能混淆。** 手册明确 DB9-1 `T/R+`=`RS485(A+)`、DB9-2 `T/R-`=`RS485(B-)`、DB9-5=`GND`。
3. **RS422 端子误接风险。** 两线半双工只使用 T/R+、T/R-、GND，RXD+/RXD- 保持悬空。
4. **USART 引脚冲突。** PA9/PA10 当前未用于三路 I2C、ADC 或 SWD，AF7 分别是 USART1_TX/RX；PC8 不再占用。
5. **接收器芯片被 USB VID/PID 混淆。** 文档明确区分 USB 串口桥身份、USB 产品身份和未披露的 RS485 芯片身份。

### 11.2 实物字段复核

- TTL VCC、PA9/PA10、R16、线长和芯片丝印均已由用户于 2026-09-04 确认；
- R16 未短接，当前无需带电或断电改变终端配置；
- 以上值将在 TASK-002 实施记录中同步到 `docs/hardware_baseline.md`。

### 11.3 当前结论

设计选择、软件接口和实物字段均已唯一确定。MAX13487E 的 5 V 供电、AutoDirection、500 kbps 限速和 3.3 V DI 兼容性均有原厂数据支持；PA10 为 FT I/O。当前 115200、约 20 cm、R16 开路的点对点方案可进入实测。

评审结论：**通过。TASK-009/010 已按本规范完成实机验证，未发现需要修改本规范的偏差。**
